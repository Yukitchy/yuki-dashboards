判定のしかた

手順

  1. 各冊の本文（物語の部分）から、字数・文の数・平均文長・文長P90・漢字割合・異なり漢字数・です・ます文の割合を数えます。文の分け方と字種の数え方は、library_check.py の物差し v2 と同じ式です。
  2. JLPT文法の検出正規表現（848項目）を当て、級ごとに何種類あたったかを数えます。自級の文法は、ありふれた語（だ・です、こと、も、と など）を除いた種類数です。
  3. 平均文長・文長P90・異なり漢字数・N4以上の文法の種類数の4つを、下の tadoku 級別中央値のあいだで線形に補間して L の値にします。4つの平均は、N5 を L0.5、N4 を L1.5、N3 を L3、N2 を L4 とする折れ線で N換算にします。
  4. N換算を四捨五入した級が現級より難しければ「1つ上に見える」、易しければ「1つ下に見える」です。つまり現級の帯は N±0.5 で、はみ出した距離で次に直す本を並べます。

指標

この判定の限界

  • tadoku の最上段は L4（7冊）で、その上は測れません。N2 は上に出ず、N1 は「N3以下に見えるか」だけを見ています。
  • tadoku は級ごとの冊数が少なく（start と L4 は7冊ずつ）、中央値は目安です。文法は正規表現のゆるい一致で、短い語は誤検出を含みます。
  • 4つの指標はどれも長さと一緒に大きくなります。話の自然さや語彙の難しさは見ていません。
  • 本に狙い文法の記録がないので、狙い文法の数は自級の文法の種類数で代用しています。
  • 漢字割合と、です・ます文の割合は物差し v2 の値で、判定には入れていません。v2警告は library_check.py が出す警告の本数です。

出どころ

  • tadoku.org の段階別読み物 91冊の実測値（数値だけを使い、原文は保存していません）
